Créaction du jeu du Pendu en Dart avec POO

Fonctionnalités principales à implémenter
	1.Choisir un mot secret aléatoire dans une liste.
	2.Masquer le mot avec des underscores (_).
	3.Permettre au joueur de deviner une lettre via des boutons A–Z.
	4.Dévoiler les lettres correctes dans le mot.
	5.Décrémenter les vies à chaque erreur.
	6.Afficher :
	  •le mot en cours,
	  •les vies restantes,
	  •les lettres déjà proposées.
	7.Détecter la victoire ou la défaite.
	8.Afficher un message final (gagné / perdu).
	9.Désactiver les boutons une fois la partie terminée.

Code Dart (logique + interface)
Le code Dart comprend :
	•La classe Pendu
	•L’affichage du mot, des vies et des lettres proposées
	•La détection de victoire/défaite
